# Operations Transport เคลียร์เคลม 48 ชั่วโมง — รุ่นขึ้น Supabase

เว็บแอปสำหรับติดตามเคสเคลม DHL / CJ ให้ปิดจบภายใน 48 ชั่วโมง
ข้อมูลเก็บบน Supabase ทุกคนในทีมล็อกอินแล้วเห็นชุดเดียวกัน แก้พร้อมกันได้

---

## ทำอะไรได้บ้าง

| หน้า | ใช้ทำอะไร |
|---|---|
| กระดานเคส | เห็นทุกเคสพร้อมนาฬิกา 48 ชม. กรองตามซับ / ขนส่ง / BU |
| คิวต้องส่งวันนี้ | เคสที่เกินหรือใกล้ครบกำหนด จัดกลุ่มตามซับ พร้อมร่างเมลทวง |
| คีย์งานเข้า | คีย์เคสใหม่ ระบบเดาซับจากทะเบียนรถให้ |
| ทะเบียนรถ | ผูกทะเบียน–ซับ แยก BU นำเข้าทีละหลายคันได้ |
| ทะเบียนซับ | ทะเบียนซับกลาง กันชื่อซ้ำ รวมชื่อที่เขียนต่างกันได้ |
| สรุป / Memo | สรุปเป็นเคสและตัวเงิน รวมและแยกรายซับ ส่งออก CSV |

## กติกานาฬิกา 48 ชั่วโมง

1. นับต่อเนื่อง 24 ชม. ทุกวัน **ไม่หักวันหยุด ไม่มีเวลาตัดยอดรายวัน**
2. เริ่มนับที่เหตุการณ์ **รับเมลครั้งแรก**
3. ปิดเคสเมื่อ **ซับรับเคลม** และหลังจากนั้นไม่มีการส่งต่อหรือรับเมลอีก
4. **ซับปฏิเสธถาวรไม่ถือว่าปิดเคส** นาฬิกาเดินต่อ
5. ส่งต่อซับใหม่ไม่รีเซ็ตนาฬิการวม แต่แยกจับเวลาของซับแต่ละรายไว้ต่างหาก

กติกาเหล่านี้อยู่ในไฟล์ `js/logic.js` — ห้ามแก้โดยไม่ได้ตกลงกันในทีมก่อน

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

ดูคู่มือทีละขั้นพร้อมภาพที่ลิงก์ที่แนบมาให้ สรุปสั้น ๆ คือ

1. สมัคร supabase.com สร้างโปรเจกต์ใหม่ เลือกรีเจียน **Singapore**
2. เปิด **SQL Editor** วางไฟล์ในโฟลเดอร์ `sql/` ทีละไฟล์แล้วกด Run
   - `01-setup.sql` สร้างตารางและกฎความปลอดภัย
   - `02-data.sql` ใส่ข้อมูล 124 เคส 95 ทะเบียน 12 ซับ
   - `03-storage.sql` สร้างที่เก็บรูปหลักฐาน
   - `04-สร้างบัญชีแอดมิน.sql` สร้างบัญชีผู้ดูแลระบบคนแรกให้เลย
     (อยากใช้อีเมล/รหัสผ่านอื่น แก้สองบรรทัดบนสุดของไฟล์ก่อนกด Run
     รันเสร็จแล้วอย่าเก็บไฟล์นี้ไว้ในที่ที่คนอื่นเปิดได้ เพราะมีรหัสผ่านอยู่)
3. คัดลอกคีย์มาวางในไฟล์ `config.js`
   - **Settings › Data API** → ช่อง Project URL
   - **Settings › API Keys** → ช่อง publishable key (`sb_publishable_...`)
     ถ้าโปรเจกต์ยังเป็นแบบเก่า ใช้แท็บ Legacy API Keys ช่อง anon public แทนได้
4. เปิด **Authentication › Sign In / Providers › Email** แล้ว **ปิด Confirm email**
   (ระบบมีการอนุมัติผู้ใช้โดยแอดมินอยู่แล้ว จึงไม่ต้องยืนยันอีเมลซ้ำ)
5. ลากทั้งโฟลเดอร์นี้ไปวางที่ **app.netlify.com/drop** จะได้ลิงก์เว็บทันที
6. เปิดลิงก์แล้ว **เข้าสู่ระบบ** ด้วยบัญชีที่สร้างไว้ในข้อ 2 ได้เลย
   (ถ้าข้ามข้อ 04 ไป ให้กด **สมัครใช้งาน** แทน — คนแรกที่สมัครจะเป็นแอดมินอัตโนมัติ)

## ทะเบียนรถรู้ว่าเป็นของซับไหน — สี่ชั้น

ระบบไม่ตั้งซับหลักให้เองเด็ดขาด แต่จะบอกว่าเดาได้ไหมและรู้มาจากไหน

| ชั้น | มาจากไหน | เชื่อได้แค่ไหน |
|---|---|---|
| 1 | ซับที่ตอบรับเคลมของทะเบียนคันนี้เอง | หลักฐานจริง |
| 2 | ซับที่ พขร. คนนี้เคยวิ่งให้ในเคสอื่น | หลักฐานทางอ้อม |
| 3 | รายชื่อรถที่ซับแจ้งไว้ (ไฟล์อ้างอิง) | คำกล่าวอ้าง หนึ่งคันมีได้หลายซับ |
| 4 | ซับสัมปทานตามสัญญา (ตั้งเอง) | ไม่ใช่หลักฐาน |

**นำเข้ารายชื่อรถของซับ**: หน้าทะเบียนรถ > นำเข้าทะเบียน > เลือกโหมด
**รายชื่อรถของซับ (ใช้ตรวจสอบ)** - ต้องมีแค่ 2 คอลัมน์ `ทะเบียน` และ `ซับ`
ทะเบียนเดียวกันใส่ได้หลายบรรทัดถ้าอยู่ในรายชื่อของหลายซับ
โหมดนี้ไม่ตั้งซับหลักและไม่แตะ BU และถ้ารายชื่อขัดกับผลตอบจริง ระบบจะติดธงให้ตรวจ

## เพิ่มคนในทีม

**วิธีที่แนะนำ — ให้เขาสมัครเอง**

1. ส่งลิงก์เว็บให้เพื่อนร่วมงาน ให้กด **สมัครใช้งาน** ด้วยอีเมลบริษัทของตัวเอง
2. ชื่อจะมาโผล่ที่ **ตั้งค่า › ผู้ใช้ระบบ** แบบ "ปิดใช้"
3. แอดมินเลือก BU ให้ แล้วกด **เปิดใช้**

**อีกวิธี — เปิดบัญชีรอไว้ให้เลย** (ใช้เมื่อเพื่อนไม่ถนัดสมัครเอง)

เปิด SQL Editor แล้วใช้ `sql/05-เพิ่มผู้ใช้ทีละคน.sql` แก้ห้าบรรทัดบนสุดแล้วกด Run ทีละคน
ตั้ง BU และสิทธิ์ได้ในไฟล์เดียวกัน · วิธีนี้เรารู้รหัสผ่านเขา จึงควรบอกให้เจ้าตัว
เข้าไปเปลี่ยนรหัสผ่านเองทันทีที่เข้าระบบครั้งแรก (ปุ่มอยู่ที่ชื่อตัวเองมุมขวาบน)

แอดมินไม่ต้องรู้รหัสผ่านของใครเลยถ้าใช้วิธีแรก และคนที่ตั้ง BU ไว้จะเห็นเฉพาะเคสของ BU ตัวเอง
ทั้งบนหน้าจอและในฐานข้อมูล (กันด้วย Row Level Security ฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนหน้าจอ)

## แก้ไขแล้วอัปเดตเว็บ

แก้ไฟล์ในเครื่อง แล้วลากโฟลเดอร์ไปวางที่ Netlify อีกครั้ง (เมนู Deploys › Drag and drop)
ลิงก์เดิมจะอัปเดตทันที ข้อมูลใน Supabase ไม่หาย

## ข้อควรรู้

- แผนฟรีของ Supabase **หยุดโปรเจกต์ชั่วคราวถ้าไม่มีใครใช้ติดต่อกัน 7 วัน**
  เข้าไปกดปลุกในหน้า Supabase ได้ ข้อมูลไม่หาย
- แผนฟรีไม่มีสำรองย้อนหลังให้ — กด **ดาวน์โหลดไฟล์สำรอง** ที่หน้าตั้งค่าสัปดาห์ละครั้ง
- เวลาทุกช่องเก็บเป็นเวลาไทยตรง ๆ ไม่แปลงโซนเวลา
